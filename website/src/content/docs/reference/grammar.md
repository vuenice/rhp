## Lexical Grammar (Logos DFA)

RHP tokenizes source code using a deterministic finite automaton (DFA) generated by `logos`:

```ebnf
Whitespace  ::= [ \t\r\n]+
CommentLine ::= ("//" | "#") [^\n]*
CommentBlock::= "/*" ( [^*] | ('*' [^/]) )* "*/"

Ident       ::= [a-zA-Z_][a-zA-Z0-9_]*
VarIdent    ::= "$" Ident
Number      ::= [0-9]+ ("." [0-9]+)? ([eE][+-]?[0-9]+)?
String      ::= '"' ( [^"\\] | '\\' . )* '"' | "'" ( [^'\\] | '\\' . )* "'"
```

## Pratt Parser Operator Precedence

Expressions are parsed using a custom Pratt parser with top-down operator precedence:

| Precedence | Operators | Associativity | Description |
| :--- | :--- | :--- | :--- |
| **100 (Highest)** | `->`, `::`, `[` `]` | Left-to-right | Property access, static calls, indexing |
| **90** | `new`, `!`, `~`, `+`, `-` (unary) | Right-to-left | Unary negation, bitwise NOT, instantiation |
| **80** | `**` | Right-to-left | Exponentiation |
| **70** | `*`, `/`, `%` | Left-to-right | Multiplicative |
| **60** | `+`, `-`, `.` | Left-to-right | Additive & string concatenation |
| **50** | `<<`, `>>` | Left-to-right | Bitwise shift |
| **40** | `<`, `<=`, `>`, `>=` | Left-to-right | Relational comparison |
| **35** | `==`, `!=`, `===`, `!==`, `<=>` | Left-to-right | Equality and spaceship |
| **30** | `&` | Left-to-right | Bitwise AND |
| **25** | `^` | Left-to-right | Bitwise XOR |
| **20** | `\|` | Left-to-right | Bitwise OR |
| **15** | `&&` | Left-to-right | Logical AND |
| **14** | `\|\|` | Left-to-right | Logical OR |
| **12** | `??` | Right-to-left | Null coalescing |
| **10** | `? :` | Right-to-left | Ternary operator |
| **5** | `=`, `+=`, `-=`, `*=`, `/=`, `??=` | Right-to-left | Assignment |
| **0 (Lowest)** | `fn`, `yield` | Non-associative | Arrow function closure |

## Statement Grammar

```ebnf
Program         ::= Statement*

Statement       ::= NamespaceStmt
                  | UseStmt
                  | ImportStmt
                  | ClassDecl
                  | FuncDecl
                  | VariableDecl
                  | ExprStmt
                  | ReturnStmt
                  | IfStmt
                  | WhileStmt
                  | ForStmt
                  | ForeachStmt
                  | MatchStmt

ImportStmt      ::= "import" String ("as" Ident)? ";"
                  | "import" Ident "from" String ";"
                  | "use" String ("as" Ident)? ";"

UseStmt         ::= "use" QualifiedName ("as" Ident)? ";"

VariableDecl    ::= TypeSpecifier VarIdent ("=" Expression)? ";"
```
